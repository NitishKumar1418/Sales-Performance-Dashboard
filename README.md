# 📊 Sales Performance & Business Analysis Dashboard

## Project Overview

The Sales Performance & Business Analysis Dashboard is a data analytics and business intelligence project developed using Microsoft Power BI.
The main objective is to analyze sales data, evaluate business performance, identify trends, and generate meaningful insights through interactive visualizations.

## Dashboard Preview

![Sales Performance Dashboard](Executive_Dashboard.png)

*Note: This image is a visual design preview. Replace it with an actual Power BI dashboard screenshot when available.*

## Objectives

- Analyze overall sales and profit performance.
- Identify top-performing products and categories.
- Evaluate regional sales and profitability.
- Understand monthly sales trends.
- Support data-driven business decisions through interactive dashboards.

## Key Features

### 1. Executive Dashboard
- Total Sales
- Total Profit
- Total Orders
- Total Quantity
- Profit Margin
- Average Order Value

### 2. Regional Analysis
- Sales performance by region.
- Profit comparison across regions.
- Category-wise regional analysis.

### 3. Sales Trend Analysis
- Monthly sales trends.
- Sales performance over time.
- Identification of business trends.

### 4. Product Analysis
- Top 10 products by sales.
- Top 10 products by profit.
- Product profitability comparison.

## Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Microsoft Excel
- Data Cleaning
- Data Transformation
- Data Visualization

## Key Business Insights

- Office Supplies is a strong-performing product category.
- Regional analysis helps identify differences in sales and profitability.
- Product-level analysis highlights the most profitable products.
- Sales trend analysis helps understand business performance over time.
